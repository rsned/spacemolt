Server v0.536.0 (announced 2026-07-20), relevant to future mission/combat work:

- **First Hunt tutorial chain** (4 missions): combat on wildlife before pirates — belt-grazers (passive) → slag-tortoises (armored) → sift-rays (fleeing) → pilot-whale (high-hull). Safe weapons-XP ramp for the idle fleet.
- **Wildlife discovery:** `get_nearby` at an asteroid belt or gas cloud; herds gather where ore/gas is still RICH — a mined-thin field means roam to a quieter system. (Ties into poi_resources depletion data: hunt where richness is high.)
- **Pirate Bounty unlocks at weapons level 1** — the First Hunt chain gets you there. Natural mission-category sequence for the learning pool: First Hunt → Pirate Bounty.
- **Pirate scout behavior:** vs a small tier-1 ship, a lone scout often engages 1v1 (winnable) instead of scan-flee-summon. Vs bigger/valuable ships they still scan → flee → send raider squad, so don't loiter after being scanned unless a scout already committed.

**Why:** mission-learn pool phase-2 wants new mission categories; First Hunt is a server-taught combat curriculum the runners could follow. Also affects risk model: being scanned by a scout in a fat hauler = leave now. [[project_mission_learning_pool]] [[project_play_as_smart_battle_handler]]
