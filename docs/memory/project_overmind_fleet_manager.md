The **overmind** is an agent-managing-agent that supervises a fleet of ~40 game agents (station residents that track market/facility data + do station-local work incl. idle local mining, plus specialized mobile workers — haulers/salvagers/explorers/miners). Three-layer brain: strategic (LLM, occasional: objective→resource/labor plan), tactical (deterministic decomposition + assignment), worker (scripted by default, LLM-on-demand). Starts as human-mission-control, evolves toward autonomous-with-override. Guardrails ("break glass") auto-act on hard dangers (combat/jettison/hull), propose on soft (credit dip).
