Operator (2026-11-15): drones pull radioactive ore without special gear, even
though catalog_items.json marks U/Th/Ra/Po `extracted_by: "rad"` (ship mining
needs a radiation-capable extractor).

**Operator's preferred radioactive setup WITHOUT a station (2026-11-15):** miningbot
SHIPS fitted with rad_harvester_i..iv and lead_lined_cargo_i/ii, based at an
outpost, mining belts 1-2 hops away and FLEEING when hostiles appear. Drones
need a docked host in-system, which an exposed outpost makes risky.

Outposts (build_outpost) are LAWLESS-only, one base per POI, members-only faction
storage + fuel bunker, no facilities and no defenses; see [[project-cloverfield-home-station]].
